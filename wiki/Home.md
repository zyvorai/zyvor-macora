# MACORA

**Your Mac's network, made clear.** A native macOS app and a zero-dependency command line tool that explain your network and tell you why it is slow.

- `macora` reads like `ifconfig`, but explains each interface and uses plain words instead of dashes.
- `macora diagnose` walks link, router, internet, DNS, HTTPS, path MTU, Wi-Fi and IPv6 bottom-up and names the lowest layer that is actually wrong.
- The app has the same engine with a window, a menu bar item and Shortcuts actions.
- Read-only by default. Nothing changes a setting unless you preview and then say `apply`.
