# Code of Conduct

We want MACORA to be a welcoming project. Everyone taking part — in issues, pull requests and discussions — is expected to:

- be respectful and assume good intent;
- give and accept feedback about the work, not the person;
- avoid harassment, discrimination, personal attacks and publishing others' private information (including their network captures);
- keep discussion on topic and constructive.

Maintainers may edit, close or remove contributions that break these rules and may block repeat offenders. Report concerns privately through a GitHub security advisory contact or by emailing the maintainers listed in `CODEOWNERS`. Reports are handled in confidence.

This policy is adapted in spirit from the Contributor Covenant 2.1.
