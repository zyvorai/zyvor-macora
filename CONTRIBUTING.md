# Contributing

Changes should preserve the JSON schema or introduce an explicitly versioned migration, use public macOS APIs, and keep mutation previews separate from monitoring. Do not add a shell call for inspection or log credentials. New configuration actions need typed validation and plan tests without editing a developer's machine.

Run the checks in docs/TESTING.md and describe which Mac/OS workflows were actually exercised. New code is contributed under Apache 2.0. Keep third-party licenses distinct; do not copy code from BUSL or other incompatible sources into this project.
